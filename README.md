# WGH Lab Converter

將西園醫院 Hemegram / Chemistry 純文字報告整理成簡短查房格式的單頁工具。

使用：<https://idnerdtw.github.io/wgh-lab-converter/>

輸出範例：

```text
0831 BUN 52 Cr 3.81 CRP 24.21 Na 149
0831 WBC 4.59 Hb 11.2 PLT 251
```

## 使用方式

1. 輸入日期，例如 `0831`、`8/31` 或 `2026-08-31`。
2. 貼上 Hemegram / Chemistry 報告。
3. 按「轉換」，再按「複製結果」。

也可下載 `index.html` 離線開啟，不需安裝套件。

## 隱私

所有解析均在瀏覽器內完成。網頁沒有後端、不送出網路請求、不使用分析服務，也不把貼上的報告寫入瀏覽器儲存空間。請勿將真實病人報告或其他 PHI commit 到 repository。
